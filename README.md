# React Hooks Visualizer

Одна страница, на которой все хуки React показаны в работе: слева минимальный пример кода,
справа — живая визуализация того, что этот код делает.

## Как это устроено

- Список хуков слева. Клик по названию плавно скроллит к демо и раскрывает его, остальные
  сворачиваются. Кнопка **«Далее»** внизу карточки делает то же самое для следующего хука.
- Открытый хук отражается в адресной строке (`#useMemo`) — ссылкой можно поделиться.
- Формат демо зависит от того, про что хук:
  - **про кеш и производительность** (`useMemo`, `useCallback`, `useDeferredValue`) — две панели
    рядом, «без хука» и «с хуком», со счётчиками пересчётов и рендеров;
  - **про жизненный цикл** (`useEffect`, `useLayoutEffect`, `useInsertionEffect`) — анимированная
    лента событий с настоящими отметками времени: render → commit → paint → effect → cleanup;
  - **про анимацию и отзывчивость** (`useTransition`, `useEffectEvent`) — движущиеся индикаторы,
    по которым видно, залипает интерфейс или нет.
- Ленты событий пишут то, что реально произошло в браузере, а не заготовленный сценарий.

```bash
npm install
```

```bash

```

Прод-сборка — `npm run build`, проверка типов — `npm run typecheck`.

## Про версии

Список из 19 хуков требует **React 19**, а не 18:

| хук | появился |
| --- | --- |
| `useId`, `useTransition`, `useDeferredValue`, `useSyncExternalStore`, `useInsertionEffect` | React 18 |
| `useActionState`, `useOptimistic`, `useFormStatus` | React 19.0 |
| `useEffectEvent` | React 19.2 |

Проект собран на React 19.2. `useFormStatus` импортируется из `react-dom`, все остальные — из `react`.

`<StrictMode>` намеренно выключен в [src/main.tsx](src/main.tsx): в dev-режиме он дважды вызывает
эффекты, и ленты событий в демо жизненного цикла читались бы вдвое.

## Структура

```
src/
  App.tsx            список хуков, аккордеон, скролл
  demos/             по одному файлу на хук: код примера, компонент демо, нюансы
  ui/kit.tsx         общие примитивы: панели, лента событий, индикация ре-рендеров
  ui/Code.tsx        подсветка кода без внешних зависимостей
```

Чтобы добавить хук, достаточно создать файл в `src/demos/` с объектом `HookDemo` и включить его в
`src/demos/index.ts`.
